JS基础语法练习

分类：学习 发布：2026-10-12 阅读时长：8 分钟

这周把 JavaScript 的基础语法过了一遍，顺便把 ES6 里常用的几个写法也试了试。代码都写在一个 js 文件里，打开这个页面按 F12 → Console 就能看到下面这些例子的输出。

一、常量和变量

const 定义常量，定义完不能再改；let 定义变量，后面可以重新赋值。

const PI = 3.14159;
let age = 18;
age = 22;          // 变量可以改

console.log('PI:', PI, 'age:', age);

二、数据类型

基本类型有字符串、数字、布尔，引用类型常用的是对象和数组。对象用键值对存数据，还能带方法：

const wenzhang = {
    biaoti: '用HTML搭建文章结构',
    zishu: 1200,
    zhengwen: function () {
        return '这是一篇讲HTML标签的文章';
    }
};

console.log(wenzhang.zhengwen());

三、条件与循环

用 if 判断分数及不及格，循环把普通的 for、for...of 和 forEach 三种写法都试了一遍：

let fenshu = [72, 45, 88, 91, 60];

for (let i = 0; i < fenshu.length; i++) {
    console.log(fenshu[i]);
}

for (let item of fenshu) {
    console.log(item);
}

四、函数

普通函数、匿名函数、箭头函数都写了。箭头函数只有一个表达式时，可以省掉花括号和 return：

function add(a, b) {
    return a + b;
}

const plus = (a, b) => a + b;   // 隐式返回

console.log(plus(10, 20));      // 30

五、模板字符串

用反引号包起来，变量放进 ${} 里，还能直接换行写多行字符串。

const product = '笔记本';
const price = 2999;

console.log(`商品：${product}，价格：${price}元`);

六、ES6+ 的常用写法

字符串的 includes() / startsWith() / endsWith()，数组和对象的解构赋值，对象字面量简写，还有扩展运算符 ...：

const [arr1, ...rest] = [1, 2, 3, 4];
const { name } = boy;

const blog = {
    ming,
    shu,
    sayHi() {
        return '欢迎来看我的博客';
    }
};
小结：语法点看着零碎，但写几遍就顺了。后面做表单校验的时候，正则和事件才是真正花时间的地方。
