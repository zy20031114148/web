成绩统计（鼠标事件）

分类：学习 发布：2026-10-15 阅读时长：5 分钟

班里这次小测的分数一直躺在表格里，干脆写个小工具整理一下。选一个及格线，点按钮就能算出及格人数、及格率，还能把及格的同学名字挑出来。

一、用到的鼠标事件

  • click：点“统计成绩”按钮时统计一次；
  • mouseenter：鼠标移上去也统计，省得点；
  • mouseleave：移出时做收尾，换肤菜单就是用这个把二级菜单收起来的。
tongjiBtn.onclick = tongji;
tongjiBtn.addEventListener('mouseenter', tongji);

二、分数存在哪

名单直接写在页面里，每个 li 用 data-fenshu 属性存分数，js 用 querySelectorAll 把这些元素取出来再读属性：

<li data-fenshu="72">张伟 72</li>

var xuesheng = mingdan.querySelectorAll('li');
var fenshu = parseInt(xuesheng[i].getAttribute('data-fenshu'));

三、动手试试

选一个及格线，然后点“统计成绩”，鼠标移到按钮上也会算一次。

  • 张伟 72
  • 李娜 45
  • 王强 88
  • 赵敏 91
  • 刘洋 60
  • 陈静 55
  • 周杰 78
  • 吴芳 100

选个及格线再点按钮。

四、统计逻辑

循环遍历每个学生，累加总分、找最高分和最低分，分数大于等于及格线的就记进及格名单：

for (var i = 0; i < zongshu; i++) {
    var fenshu = parseInt(xuesheng[i].getAttribute('data-fenshu'));
    zongfen += fenshu;

    if (fenshu >= xian) {
        jigeRenshu++;
        jigeMingdan.push(xuesheng[i].textContent);
    }
}
及格的同学名字会自动变绿，一眼就能看出来。
