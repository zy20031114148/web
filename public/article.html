用HTML搭建文章结构

分类：学习 发布：2026-09-07 阅读时长：6 分钟

这周把 常用 HTML 标签 集中过了一遍，把它们分成三类：head 内的标签、body 内的标签 和 结构化语义标签。记下来方便以后翻。

一、head 内的标签

<head> 标签里通常放的是不会直接显示在页面里的内容，但浏览器会用到：

  • <meta charset>：声明字符编码，避免中文乱码。
  • <meta viewport>：移动端响应式必备。
  • <meta name="description">：SEO 描述。
  • <title>：浏览器标签页的标题。
  • <link rel="stylesheet">：引入外部 CSS。
  • <style> / <script>：内嵌 CSS / JS。

二、body 内的常用标签

这部分是真正显示在页面里的内容，按用途可以再分：

1. 文本与排版

  • <h1> ~ <h6>：标题，h1 最重要，递减。
  • <p>：段落。
  • <span>：行内容器，常用于局部样式。

2. 链接与媒体

  • <a>：超链接，href 指定目标。
  • <img>：图片，src 和 alt 必填。
  • <figure>：媒体内容区块，常配合 <figcaption>。

3. 列表与表格

  • <ul> / <ol> / <li>：无序/有序列表。
  • <table> / <tr> / <th> / <td>：表格。

4. 表单

表单是交互的关键，由 <form> 包裹，里面放各种控件：

<form action="#" method="post">
    <input type="text" name="user" placeholder="用户名">
    <input type="email" name="mail" placeholder="邮箱">
    <textarea name="msg"></textarea>
    <button type="submit">提交</button>
</form>

三、结构化语义标签

语义化标签让结构对人和机器都更友好。比起满屏的 <div>，用这些标签写出来的网页可读性强很多：

语义化标签的好处：① 利于 SEO；② 利于屏幕阅读器无障碍访问；③ 提高代码可读性。
标签用途
<header>页头或区块头部
<nav>导航区
<main>主体内容（每页一个）
<section>主题性内容分组
<article>独立可分发的内容（文章/帖子）
<aside>侧边栏、次要信息
<footer>页脚或区块底部

四、小结

这次复习下来，最大的感受是：HTML 看似简单，但想写得"标准"不容易。光知道每个标签是干什么的还不够，还要知道什么时候该用、什么时候不该用。后面开始学 CSS 之后再来把这些结构美化一下，应该会顺畅不少。
